## About project
This engine has a simple script **interpreter** and has **SDK**.

Here is the technical specification

| **Build system** | `Go Modules` | `-` |
## How to start
a. clone repository: 
```bash
git clone https://github.com/lev445/A-Engine.git
```
b. change directory to project directory 
```bash
cd A-Engine
```
c. install dependencies
```bash
go mod tidy
```
